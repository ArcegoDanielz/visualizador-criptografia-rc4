# Visualizador e Criptografador da Família RC (RC4)

Aplicação web interativa desenvolvida para o trabalho acadêmico de Criptografia, com foco na implementação e visualização didática do funcionamento interno dos algoritmos da família **RC (Ron's Code / Rivest Cipher)**.

## 🚀 Tecnologias Utilizadas

- **Front-end:** React 18 / Next.js 14
- **Interface Gráfica:** Material UI (MUI v5)
- **Lógica de Criptografia:** JavaScript Puro (Engine RC4)

## 📌 Funcionalidades

- Criptografia e descriptografia de mensagens em tempo real.
- Visualização do estado interno do vetor de permutação $S$ (KSA e PRGA).
- Exibição do *Keystream* gerado e conversão de saída para Hexadecimal.
- Interface responsiva com suporte a Dark/Light Mode via MUI.
